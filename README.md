# Bruna Personaliza Love

Site institucional da Bruna Personaliza Love, publicado via GitHub Pages.

## Estrutura

- `index.html`: página principal
- `assets/css/`: estilos
- `assets/js/`: interações, filtros e CTAs
- `assets/images/brand/`: logos e favicon
- `assets/images/products/`: fotos organizadas por categoria
- `CNAME`: domínio personalizado do GitHub Pages
- `robots.txt` e `sitemap.xml`: indexação

## Publicação

O repositório pode ser publicado diretamente pelo GitHub Pages usando a branch `main` e a pasta raiz.
